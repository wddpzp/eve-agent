Use this when the user asks to write a changelog or release-notes entry.

Write the entry in Keep a Changelog style:

## [<version>] - <YYYY-MM-DD>

### Added
- new features

### Changed
- changes to existing behavior

### Fixed
- bug fixes

Only include sections that actually have entries. Keep every bullet to one line, imperative mood ("Add dark mode", not "Added dark mode support for users").
